- **Русская раскладка ПК.** Запустите `scrcpy`, откройте поле ввода на телефоне и переключайте EN/RU на компьютере. Кириллица, включая `Ё/ё` и `№`, передаётся без дополнительной латинской буквы. В стандартном режиме SDK для этого нужны Android 7+ и поле, поддерживающее вставку.
- **Чёрные поля.** В полноэкранном режиме (`scrcpy -f` или F11) свободное пространство вокруг изображения теперь чёрное (`#000000`). Пропорции и запись экрана не меняются. Прежний серый можно вернуть параметром `--background-color=222222`.

Для кириллицы SDK кратковременно использует буфер Android: после обработки вставки восстанавливает прежнее содержимое, если другая программа его не изменила. Для паролей, игр или приложений без вставки используйте `scrcpy -K` и настройте русскую физическую раскладку на Android (Alt+K). `--no-clipboard-autosync` и `--legacy-paste` отключают использование буфера при наборе.

Для обычного 64-битного ПК с Windows скачайте **`scrcpy-win64-v5.0.3.zip`**, распакуйте целиком и запустите `scrcpy.exe`. Контрольные суммы архивов и сервера приведены в `SHA256SUMS.txt`.
