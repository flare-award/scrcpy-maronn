**Для телефона с экраном 90 Гц на Windows:** скачайте `scrcpy-win64-v5.1.0.zip` (для обычного x64 ПК), распакуйте целиком, откройте **`scrcpy-fps.bat`** и нажмите **3**. На любой платформе эквивалентная команда — `scrcpy -m1280 -b6M --max-fps=90 --print-fps`.

- **Меньше нагрузки на телефон.** Обычный `scrcpy` ограничивает длинную сторону зеркала 1600 пикселями. Разрешение самого телефона не меняется. Для родного разрешения запустите `scrcpy -m0`. Размер видео при записи, захват с камеры, V4L2 и `--new-display` по умолчанию не изменились.
- **FPS можно менять в окне scrcpy.** Левый **Alt+1 / 2 / 3 / 4** задаёт предел 30 / 60 / 90 / 120 кадров/с, **Alt+0** снимает предел. Звук и подключение сохраняются, видеопоток ненадолго перезапускается. **Alt+i** — счётчик в консоли. Для игр с сильными фризами начните с первого пункта меню: `scrcpy -m1024 -b3M --max-fps=30 --print-fps`.
- **Высокая частота зеркала.** На Android 14+ scrcpy запрашивает выбранную частоту у виртуального дисплея; при отказе прошивки остаётся обычный захват. На старых версиях используется только ограничитель кодировщика (официально с Android 10). Это не разгон дисплея: результат зависит от приложения, кодировщика, соединения и частоты монитора ПК. Проверьте FPS во время прокрутки, а не на неподвижном экране.

Русский ввод и чёрные поля из 5.0.3 сохранены. Клиент и сервер берите из одного выпуска. Контрольные суммы — в `SHA256SUMS.txt`.
